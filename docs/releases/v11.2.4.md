Qt 기반 64비트 카카오톡(`KakaoTalkUI.exe`)을 인식하고 GIF·움직이는 WebP 사진을 자동으로 받아 말풍선에서 반복재생해요. 확장자가 없는 묶음 WebP도 각 사진의 원본 정보로 연결해요.

- 원본 최대 4건 동시 요청, 동일 원본 중복 방지, 완료 순서에 관계없는 처리.
- 일시 오류와 60초 초과 요청은 간격을 두고 최대 3회 시도해요. 만료된 원본은 재시도하지 않아요.
- 화면 밖 요청과 재생 객체를 정리하고, 창이 다시 열리면 연결해요.
- 다운로드 완료 수와 재생 상태 표시를 보완하고 진단에 프레임·반복·재시도 수치를 추가했어요.
- 기존 32비트 재생 경로를 유지하면서 GDI 포인터/구조체 처리와 생성 직후 프레임 해제 문제를 보완했어요. 기존 4K 최적화도 포함돼 있어요.
- 트레이, 자동 시작 설정 이전, 업데이트, 진단 ZIP은 공통으로 사용해요.

검증: Qt 26.10.0.492에서 개별 GIF, 묶음 WebP, 새 WebP 원본 자동 다운로드와 여러 원본 동시 반복재생을 확인했어요. 자체 x86/x64 렌더러 및 다운로드 큐·종료·업데이트·진단 테스트도 수행했어요.

제한: 실제 32비트 카톡의 묶음 사진 종단 검증은 남아 있어요. ZIP으로 전달된 구형 구조의 64비트 `KakaoTalk.exe` 원본 자동 다운로드는 이번 지원 대상이 아니에요. 모든 카톡 버전이나 4K 환경의 성능을 보장하지 않아요.

기존 프로그램에서 **업데이트 확인 → 업데이트 설치**를 선택하거나 `KakaoAutoPlay.exe`를 직접 받아 실행하세요. Python이나 PowerShell을 별도로 설치할 필요는 없어요. 로컬 시험판 11.2.1에서도 이 정식 버전을 업데이트로 받을 수 있어요.

배포 검증 보완: Windows 경로 별칭 비교와 시험 프로그램 준비 파일의 동시 읽기 문제를 수정했어요. 11.2.2와 11.2.3은 테스트 단계에서 중단되어 정식 Release로 공개되지 않았어요.
