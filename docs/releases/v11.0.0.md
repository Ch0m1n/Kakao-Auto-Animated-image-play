# Kakao AutoPlay v11.0.0

- 프로그램 UI에 현재 버전과 업데이트 확인 버튼을 추가했어요.
- 이 GitHub 저장소의 정식 Releases에서 새 EXE를 확인하고 설치할 수 있어요.
- 다운로드 크기/SHA-256 검증, 기존 재생 작업 정상 종료, 새 버전 실행과 자동 시작 설정 인계를 지원해요.
- GitHub Actions에서 태그별 실행 파일을 빌드·배포하는 작업을 추가했어요.

기존 v10 이하 사용자는 이 버전을 한 번 직접 받아 실행해 주세요. 이후에는 프로그램 안에서 업데이트할 수 있어요.

Windows x64용 단일 EXE이며 별도 Python 설치는 필요 없어요. 기존 도우미를 중지한 뒤 실행해 주세요. 카카오톡 내부 구조에 의존하는 개인용 실험 프로그램으로, 모든 카톡 버전·DPI 환경에서의 동작을 보장하지 않아요.
