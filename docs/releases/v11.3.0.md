# Kakao AutoPlay v11.3.0

- 지정한 채팅방·발신자의 일반 사진과 채팅 칸을 함께 최대 64×64픽셀로 축소합니다. 원래 비율을 유지합니다.
- 발신자는 쉼표로 여러 명 지정할 수 있고 괄호 별칭은 생략할 수 있습니다. 이름과 사진 사이에 글이 있어도 적용합니다.
- 선택한 사진을 가리고 마우스를 올렸을 때만 표시하는 옵션을 제공합니다.
- 정상 종료하거나 규칙을 해제하면 사진의 원래 크기를 복원합니다.

사진 필터는 기존 32비트 카카오톡 26.10.0.5364의 일반 사진 메시지에서 확인했습니다. 이름이 화면 밖에 있으면 처음 적용이 지연될 수 있습니다. 버튜버 등 내용 자동 분류 기능은 없으며 묶음 사진·이모티콘 상품 전체에 대한 지원을 뜻하지 않습니다. Qt 64비트의 기존 움짤 재생 기능은 유지됩니다.

기존 v11 이상 사용자는 **업데이트 확인**으로 설치할 수 있습니다. 새로 받는 경우 첨부된 **KakaoAutoPlay.exe 하나만** 실행하세요. 채팅방·발신자 규칙은 각자의 옵션에서 지정하며 특정인의 이름은 배포 파일에 포함하지 않습니다.
