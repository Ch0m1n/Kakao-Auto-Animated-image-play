# Kakao AutoPlay v11.1.0

- X 버튼은 기본으로 트레이에 숨기고 GIF/WebP 재생을 유지해요.
- 트레이 메뉴에서 열기, 옵션, 완전 종료를 사용할 수 있어요.
- 상단 옵션에서 X 버튼 동작을 트레이 숨김 / 바로 종료로 선택하고 저장해요.
- 예전 파이썬 도우미와 번들의 자동 시작 등록을 새 EXE로 이전해요. 로그인하면 트레이에서 재생을 시작해요.
- 같은 버전을 다시 실행하면 기존 창을 열어 중복 실행을 막아요.
- v11에서는 업데이트 확인 버튼으로 받을 수 있어요.

Windows x64 개인 실험용 도우미예요. 게임 중 사용자 요청으로 실제 트레이 클릭 검증은 생략했어요.
